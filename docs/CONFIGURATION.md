# 配置与使用

本页说明后台操作与配置何时生效。首次启动见[项目 README](../README.md)，服务器、备份与搬迁见[部署指南](DEPLOYMENT.md)。环境变量完整示例以 [`.env.example`](../.env.example) 为准。

## 初始配置

首次安装后复制 `.env.example` 为 `.env`，已有配置不要覆盖。需要配置：

| 变量 | 用途 |
| --- | --- |
| `ADMIN_USER` | 管理员登录名；当前为单管理员模型 |
| `ADMIN_PASSWORD_HASH` | scrypt 密码哈希，不保存明文密码 |
| `SESSION_SECRET` | 随机长字符串；生产环境拒绝弱值或占位值 |
| `SITE_URL` | 正式站点绝对 URL，供 RSS、sitemap、canonical 使用 |
| `ADMIN_PORT` | 后台端口，默认 4000；开发代理使用同一值 |
| `COOKIE_SECURE` | 本地 HTTP 为 false，HTTPS 部署为 true |

PowerShell 7 可通过标准输入生成密码哈希，避免把密码写进命令历史：

```powershell
$adminPassword = Read-Host '设置后台密码' -MaskInput
$adminPassword | npm run admin:hash
Remove-Variable adminPassword
node -e "console.log(require('node:crypto').randomBytes(48).toString('hex'))"
```

将脚本输出的哈希填入 `ADMIN_PASSWORD_HASH`，将随机字符串填入 `SESSION_SECRET`。修改凭据后重启后台；不要公开终端输出中的密钥。无需更改依赖版本或向源码写入个人账号。

## 配置与生效时间

| 管理入口或数据 | 存储位置 | 生效规则 |
| --- | --- | --- |
| 文章与随笔、草稿/撤回/删除 | `src/content/` | 保存后构建发布；草稿不生成公开页面或索引 |
| 品牌、头像与页标、顶部入口、首页/关于/页脚、默认外观 | `data/profile.json` | 保存后构建发布 |
| 项目详情、首页精选项目 | `data/projects.json` | 保存后构建发布 |
| 项目/关于页的统一项目清单与 GitHub 星标 | 项目 JSON、站点配置、GitHub 缓存 | 构建时统一采集，列表、详情、星标与 sitemap 一起发布 |
| 网址导航 | `data/nav.json` | 保存后构建发布；区别于 profile 中的顶部页面入口 |
| 友链、公告、歌单 | 对应 `data/*.json` | 保存、审核、排序或删除后统一构建发布 |
| 评论、审核、博主回复、评论配置 | `data/twikoo/` | 运行库实时接收；公开评论、回复、点赞与设置在构建发布后同步 |
| 开站日期、访问量、评论量 | `data/` 及评论库 | 公开展示取发布快照；后台实时统计，开站日期也需发布 |
| 随机壁纸池 | `public/wallpapers/` | 新增或删除后构建发布；每次进入首页从已发布清单随机选择 |

`profile.json` 缺失字段使用默认值；显式清空的社交链接等保留空值。表单文字预览不等同完整前台渲染。页面显示“保存成功”只说明待发布数据已写入。所有前台展示都以成功构建发布为准。构建期间后台内容写入返回 409，完成后可重试；访客评论、友链申请与访问打点继续写运行库，等待下次发布后展示。运行时长按已发布开站日期自然递增，临时播放地址与验证码按需处理。首次升级后需进行一次完整发布；缺少新快照的旧 release 不回退读取后台源数据。

## 写作与媒体

1. 访问 `/admin`，在「文章」或「随笔」新建内容。文章标题必填，随笔日期必填；无效日期在落盘前拒绝。
2. 使用路径/slug 决定 URL。中文路径受支持；编辑路径会迁移文件，已存在的目标路径不会被覆盖。
3. 保存 Markdown，可预览、插图或设为草稿。未保存离开时会提示。
4. 在「构建发布」发布，并用后台「查看网站」核对已发布版本。

图片写入 `public/uploads/`，限制 10MB，校验类型及文件头，SVG 剥离脚本能力，重复内容复用已有文件。媒体页可展开“查看使用位置”，区分待发布内容、回收站和当前线上引用，并跳转编辑。仍被待发布内容或回收站引用的图片禁止删除；只有线上引用时可删除源文件，已发布副本仍保留至下次发布。站外使用无法追踪。删除文章与随笔先进入回收站，可恢复或彻底删除；恢复后也需要构建发布。

前台搜索覆盖公开文章的标题、摘要、分类、标签与关键词，不是正文全文搜索。内容字段及存储规则见[开发指南](DEVELOPMENT.md#内容字段)。

## 外观与阅读

后台设置站点默认风格（life、swiss、minimalist、glass、brutalist）、明暗主题、背景和页面区块。访客自行设置的风格/主题优先，保存在其浏览器；「恢复站点默认」清除对应偏好，不修改服务端。

默认 life 使用暖纸背景与陶土强调色，前台使用得意黑。后台外观与密度在顶栏调整；`Ctrl/Cmd + K` 打开快捷搜索。内容管理提供表格、看板、状态矩阵、时间轴和分类关系图，列表支持筛选与分页。

光标设置独立保存在访客浏览器：默认保留自定义箭头、关闭平滑跟随。主动开启后默认柔和度 70ms、幅度 24px、宽度 24px，可调整悬停、按下缩放及过渡时长。「恢复光标默认」不清除主题偏好。触屏不启用自定义箭头；减少动画时暂停跟随和缩放。

目录按章节 ID 定位，保留导航下方留白；重复点击同一章节仍有效。减少动画时立即定位，页面切换会清理动画、监听器和观察器。横向轨道使用渐进模糊且不阻挡点击。

顶部液态玻璃使用本地生成位移贴图，不读取壁纸像素，也不依赖 CDN。不支持 SVG 背景滤镜时回退到普通毛玻璃；减少透明度时使用不透明底色；减少动画时保留静态材质。实现位置和浏览器检查见[开发指南](DEVELOPMENT.md)。

## 随机壁纸

将 JPG、JPEG、PNG、WebP、AVIF 或 GIF 放在 `public/wallpapers/` 顶层，文件名可含中文与空格。忽略子目录、隐藏文件、SVG、视频和符号链接/junction，目录本身也不能为链接。

后台「页面内容 → 默认外观」选择随机、固定背景或渐变，模式修改需发布。随机模式每次进入/刷新首页重新选择，多图时尽量不重复上一张；无可用图片时依次回退到 `hero.backgroundUrl` 和渐变。固定模式只使用指定图片或视频。

后台通过鉴权接口 `/api/manage/wallpapers` 预览源目录；前台 `/api/public/wallpapers` 只返回已发布清单，图片也读取对应 release；纯静态托管使用构建清单。壁纸不进 Git，但会进入你主动发布的静态站点。自动备份未覆盖该目录，应另行保存，详见[备份范围](DEPLOYMENT.md#备份了什么)。

## 项目与 GitHub

后台「项目」管理详情、封面、技术栈和精选。`src/data/site.config.json` 的 `githubUser`、`githubRepo`、`projectOverrides` 和 `projectGroups` 控制账号、仓库链接、单仓库补充及手动分组；仓库默认是空博客配置，不预置个人仓库清单。

关于页与项目页使用同一合并契约，纳入公开非 fork 仓库与后台项目、去重并按星标排序；本地独立项目不显示虚构 Star。发布时采集 GitHub 公开元数据，HTML 与 API 共用同一目录。断网或限流优先使用已保存的完整缓存；不会因页面加载或悬停而改变线上清单。

## 音乐、友链与公告

音乐以后台管理歌单为主，无需配置网易云歌单 ID 也可播放本地音频。支持 mp3、flac、wav、m4a、ogg、aac，最大 30MB，服务端先校验类型和基础容器/帧头，再写入文件与歌单；实际编码还需浏览器支持。下架或删除全部歌曲并构建发布后隐藏播放器；无后台时也只读取静态发布快照，不在浏览器重新拉取外部歌单。

`PUBLIC_NETEASE_PLAYLIST_ID` 与 `PUBLIC_MUSIC_API` 为可选配置；网易云导入/播放受解析服务、版权、地区等条件限制。修改构建期公开变量后需重新构建，不据本地 WAV 测试承诺远程曲源可用。

友链申请先进入待审，同 URL 重复申请视为更新；只有 approved 项公开。公告需启用且在有效期内才显示。审核、上下架和有效期统一按构建取样生效，保存后必须构建发布。

## 评论

默认随 `npm run admin` 启动官方 Twikoo，本地持久化无需单独申请数据库。后台支持搜索、回复、隐藏/公开、删除，以及复用博客会话的官方完整管理面板。数据库迁移、外部服务与恢复说明集中在 [Twikoo 手册](TWIKOO.md)。

## 常见问题

- 保存后线上没变：先确认该模块的生效规则，再检查发布结果；dev 的源码页面与 current 发布快照不同。
- 删文发布后 dev 异常：删除检测会重建 Astro 缓存，重启开发服务。
- 改默认风格后自己看不到：浏览器已有访客覆盖值，使用「恢复站点默认」。
- 评论/友链/歌单不可用：纯静态预览没有 Express 动态 API，需同时启动后台或配置生产反向代理。
- 端口占用：前台可用 `npm run dev -- --port 4322`，后台修改 `.env` 的 `ADMIN_PORT` 并重启。
