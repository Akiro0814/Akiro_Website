# Spring UI 浏览器回归

运行：`node scripts/check-public-ui.mjs`（或集成后的 `npm run test:public-ui`）。

脚本启动独立的 Astro 开发服务器 `127.0.0.1:4331`，结束时关闭进程树。可用 `PUBLIC_UI_PORT` 覆盖端口，或设置 `PUBLIC_UI_URL` 检查已启动的前台。端口被占用时直接失败；子进程设置 `ASTRO_DEV_BACKGROUND=1` 并使用 `--ignore-lock`，避免 Astro 7 在代理环境自动派生后台服务，也不复用或接管其他预览。使用仓库真实的公开内容，不登录后台；浏览器预先启用现有 API 降级开关并阻断 `/api/**`，避免访问统计和其他接口写入运行数据。因此本回归仅证明前台行为，不证明后台 API 或发布数据同步。

验收范围：

- 全屏开场、桌面文章横轨与移动端原生横滑。
- 五种视觉风格和手动、时间、滚动三种模式的可操作状态。
- 刷新与 Astro 客户端换页后的风格保留。
- 外观面板及导航的 Escape 关闭、展开状态和焦点恢复。
- 固定前台路由和从真实内容链接发现的详情路由，在 1440px 与 390px 下无页面横向溢出。
- 换页后横轨 pin 残留、减少动态效果下的可读性、JavaScript 运行异常。
- 站点统计及数值在显现后保持可见，文档根元素不会被误赋 `aria-pressed`。

截图输出 `docs/assets/spring-ui/`；这些截图包含真实公开内容，供人工验收使用，不纳入源码提交。
