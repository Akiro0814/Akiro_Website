# 官方 Twikoo 集成

公开展示统一在后台构建发布后更新：访客提交、点赞以及后台审核、回复、删除、配置修改先写入运行库，发布时生成脱敏快照。前台评论树、分页、计数和最近评论读取当前 release；失败构建保持旧版，回滚恢复对应展示快照，不覆盖运行库。

本项目使用同版本的官方 `twikoo`、`tkserver` 与 `@twikoojs/common` 2.0.15，不再将自写的协议兼容接口称作 Twikoo。官方参考：[快速上手](https://twikoo.js.org/quick-start.html)、[自托管部署](https://twikoo.js.org/backend.html#私有部署)、[前端部署](https://twikoo.js.org/frontend.html)。

## 本地使用

```powershell
npm ci
npm run admin
# 另一个终端
npm run dev
```

无需额外申请 MongoDB。默认使用官方支持的 Loki 持久化数据库，数据在 `data/twikoo/`，由同一个博客后台进程管理。生产环境继续沿用 `/api/`、`/admin/`、`/admin-assets/` 的既有反向代理。Twikoo SDK 和 CSS 均在本站提供，不依赖浏览器从 CDN 加载核心脚本。

文章评论区与随笔留言区使用官方 SDK；回复、点赞、表情、草稿、预览、本人删除等由官方组件处理。划词引用仍可把选中文本写入评论框。图片上传、验证码、通知等依赖的第三方服务在 Twikoo 管理面板按实际服务参数配置，未配置不会伪造成功。

## 后台管理

登录博客后台，进入「评论」：

- 搜索昵称、邮箱、页面与正文，筛选可见/隐藏评论。
- 回复评论，前台显示博主身份；隐藏/公开、删除评论。快捷删除主楼会一并清理回复。
- 点击「Twikoo 完整管理」，使用官方面板管理评论、配置审核规则、站点信息、表情、邮件、图床、验证码以及导入导出。

官方面板复用博客登录和 CSRF 校验，不需要额外注册 Twikoo 管理密码；密码设置与退出应使用博客自身入口。桥接令牌由服务器保管，不写入前台 JS、HTML 或浏览器存储。公开接口不开放密码初始化、后台配置、导入导出及删除他人评论等管理操作。

Twikoo 会允许作者本人看到自己被隐藏/待审的评论。判断隐藏是否对外生效，应使用另一个未登录访客浏览器，而不是仅刷新原作者的窗口。

## 旧数据与持久化

首次使用时，自动将 `data/comments.json` 中的评论迁入官方数据库，保留原 ID、回复关系、状态、时间与历史点赞数；原文件不改写。迁移标记与新库一起持久化，之后在新库删除的评论不会因为重启再次从旧文件复活。

后续评论和审核只写新数据库。Loki 的数据库调用按顺序执行，每次变更保存后再确认成功；异步审核/通知也经过同一数据库适配器，避免后台任务遇到关闭中的数据库。正常停止后台会等待请求与后置任务完成后关闭数据库。`data/twikoo-summary.json` 只用于构建时统计快照，不是评论数据库。

备份与恢复应保存整个 `data/twikoo/` 目录；默认数据备份覆盖 `data/`。复制/恢复数据库目录时先停后台，不要让两个进程同时使用同一 Loki 目录。也可在官方面板导出评论，但评论导出与整个数据库备份不同，配置与密钥仍需另行保存。恢复评论导出到全新库时，应先另行保留并移走旧 `comments.json`，避免首次启动自动迁移后又重复导入同一批评论。

## 可选配置

| 变量 | 作用 |
| --- | --- |
| `TWIKOO_DATA` | 本地数据目录，默认项目 `data/twikoo/` |
| `MONGODB_URI` / `MONGO_URL` | 改用 MongoDB，留空使用 Loki |
| `TWIKOO_ENV_ID` | 已有外部 HTTP(S) Twikoo 服务地址；留空使用本站官方服务 |
| `TWIKOO_ADMIN_TOKEN` | 外部服务或已有非托管数据库的管理访问令牌，仅服务端使用 |
| `PUBLIC_TWIKOO_ENV_ID` | 旧配置兼容项，优先级低于 `TWIKOO_ENV_ID`，只支持 HTTP(S) 服务地址 |

从 Loki 切换 MongoDB 或外部服务时，先在官方面板导出评论，准备目标环境，再导入并核对数量与回复。不会自动把已有 Loki 数据复制到另一数据库。腾讯云 CloudBase 的纯环境 ID 不是 HTTP 地址，不可直接填到服务端代理；本次验证覆盖默认自托管模式，不证明外部云环境连通性。

邮件通知需填写自己的 SMTP/邮件通道及博主邮箱。默认保留地址 `blogger@localhost.invalid` 仅用于无额外配置时的博主身份识别，不是可接收邮件的真实地址。
