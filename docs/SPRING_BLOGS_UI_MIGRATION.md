本次核对覆盖全局布局、样式变量、首页组件、导航、文章列表、便签、关于页，以及平滑滚动、图片视差、磁吸和风格控制台源码。尚未运行参考站点，源码中依赖服务端配置的实际背景和内容不能视为已验证的线上外观。

## 实施方式

推荐在现有 Astro 内重建参考项目的视觉与动效。原有 Express 内容管理、Markdown、动态接口、鉴权与发布机制继续承载业务，原页面 URL 保持可用。GSAP 已是现有依赖，可复用；如加入 Lenis，仅用于前台滚动协调。

另外两种方式不作为默认实施方案：只覆盖 CSS 改动较少，但无法还原全屏开场和横向轨道；整体切换 Next.js 可沿用参考组件结构，但会扩大到内容、路由与发布系统重构，超出本次视觉迁移目标。

## 视觉范围

- 以参考默认 life 风格为基准：奶油浅底、深绿墨色、陶橙强调色、细边线、圆角卡片、低强度颗粒背景和宽松的分区节奏；同步适配深色。
- 复现参考的风格控制台及其生活、瑞士、极简、玻璃、粗野样式能力，包含手动、时间和滚动驱动切换；颜色与字体通过集中变量管理。
- 中文保留可读且完整的字形回退；英文字体按参考的标题与正文层级配置。保留本站品牌、头像及可编辑文案。
- 后台现有暖色珍珠玻璃界面不在本仓库前台参考的迁移范围内。

## 排除与适配边界

不增加本站没有的恋爱纪实、愿望清单、时间胶囊、岁月信箱、足迹地图、私人相册、成就系统、鱼塘业务，也不复制作者的私人内容、身份文案或服务端接口。相册横向轨道的通用视觉可用于本站已有项目展示；不据此新建相册业务。

页脚角色探头等装饰采用本站可用素材时才展示，不直接引入参考作者的身份角色。参考媒体缺失或加载失败时仍须保持布局与文字可读。参考仓库 README 标明尚无 LICENSE：实施以视觉和交互重建为主，第三方素材复用应逐项确认来源并记录。

## 动效规格与生命周期

- 首屏依次上移显现：参考位移 26px、时长 0.9s、间隔 0.07s、power3.out；区块卡片参考 24px、0.75s。
- 横向轨道仅在桌面、实际存在溢出且未开启减少动画时固定，参考 scrub 0.8；窗口变化、字体和图片加载后重新测量。
- 图片采用遮罩显现、轻度视差及悬停缩放；横向轨道内关闭容易造成图片隐藏的纵向遮罩逻辑。
- 便签倾斜幅度约 3.5 度；按钮采用轻度磁吸、按压与回弹。仅在精细指针设备开启跟随效果。
- 平滑滚动与 ScrollTrigger 共用更新节奏；弹窗、播放器列表和其他独立滚动区域不被全局滚动拦截。
- 对 Astro 换页建立统一初始化及清理机制，释放 GSAP context、ScrollTrigger、ticker、观察器和页面监听，避免重复绑定、残留固定占位与音频中断。
- 减少动画模式停用固定横移、打字循环、波浪循环、磁吸和视差，保留静态信息与原生滚动；无 JavaScript 时正文及主要导航仍可用。

## 验收

1. 为所有现有前台路由建立桌面和移动端截图，核对布局、间距、明暗主题和长标题。
2. 浏览器验证导航往返、移动菜单、外观面板、主题持久化、滚动轨道、窗口缩放与减少动画，检查控制台异常。
3. 回归搜索、分类标签、文章目录、评论、友链表单、音乐播放器及空数据场景；依赖外部服务的结果单独标注。
4. 执行项目 `npm run verify`，并运行现有后台 UI 回归以发现共享改动造成的影响。迁移新增的交互以必要浏览器回归覆盖。
5. 交付实际代码、页面截图、迁移对照和验证记录。发布到线上不包含在本次本地实施内。

## 实施与验证结果

用户已确认优先还原视觉、允许必要时更换技术栈，且要求全面使用 Akiro。实际实现无需更换技术栈：新增 Lenis，使用现有 GSAP/ScrollTrigger 和 Astro 页面生命周期实现。
