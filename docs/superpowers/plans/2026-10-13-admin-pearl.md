# 后台视觉移植执行计划

直接在当前工作区实施，保留已有未提交变更，不主动提交。

1. 新建 ui-model.js 与行为单测：外观规范化、安全命令过滤、真实内容关系数据。先执行失败测试，再实现。
2. 新建 pearl.css：公共视觉令牌、材质、框架、全页面控件、登录、图表、视图和响应式。通过 views.mjs 统一引入；旧 CSS 保留以覆盖业务特有布局。
3. 新建 motion.js 与 login-scene.js，提供 GSAP 统一运动、共享元素浮层、数字、图表及可暂停网络画布；GSAP 从已安装依赖同源提供。
4. 新建 interface.js：主题、密度、导航、命令、账户、下拉、确认、Toast、列表筛选分页与可视化；每次页面初始化清理旧监听。
5. 修改 admin.js：保留 API 与业务函数，仅接入视觉服务，异步确认、导航过渡及正确的过期请求取消。修改 dashboard.js：图表颜色读取令牌，更新后触发视觉增强。
6. 新建 visualizations.js：内容看板/关系舞台、导航星系、版本阶梯、发布流程、设置样本卡；依据现有数据，支持平移缩放、键盘与减少动态。
7. 新建隔离预览脚本与浏览器验收，修复功能与布局问题；运行 npm run verify，记录交付覆盖和限制。
