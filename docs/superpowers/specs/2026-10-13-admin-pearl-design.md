# 后台暖色珍珠玻璃视觉移植

用户已在当前会话确认完整视觉清单，并要求开始实施。参考 scaffold-master 577079e；本次保留 Express、Cookie/CSRF、Markdown/JSON、Astro 构建发布与备份，视觉层使用原生模块与本地 GSAP，不引入 Java 或 Vue 运行时。

## 交付范围

1. 暖白阅读面、淡红高光、陶土强调色、玻璃浮层、凹槽、颗粒、分级圆角阴影；保留霞鹜文楷，读数使用等宽数字。
2. 可折叠侧栏、滑动选中块、玻璃顶栏、面包屑、账户菜单、移动导航、外观与密度设置、命令面板。
3. 全部现有页面的按钮、字段、表格、标签、分页、状态、确认框、提示堆与表单布局。
4. 页面级联、按压回弹、指针高光、涟漪、浮层展开、共享元素抽屉、卡片重排、图表描绘与数字滚动。
5. 暖色网络登录画布、时钟、倾斜登录卡、真实登录成功动画。
6. 现有内容映射为表格/看板与分类关系舞台，导航映射为分类画布；版本映射为阶梯、构建映射为流程。所有视图用现有真实数据，无模拟业务或虚构指标。
7. 原项目的用户/角色矩阵、组织与代码生成业务不新增；对应视觉语汇在博客内容、导航、设置与发布视图复用。无小时统计时不伪造 7×24 热力。

## 安全与兼容

视图切换不克隆带事件的节点；保留字段 ID、data 属性和业务绑定。用户文本通过 textContent/转义输出。确认对话框使用异步 Promise，快捷键只操作顶层浮层，保留编辑器未保存保护。界面偏好只写浏览器，支持深色、系统、密度、减少动态。动画在页面隐藏时结束或暂停，导航竞态不得提交过期页面。

## 验收

运行 npm run verify；浏览器检查登录失败/成功、所有后台路由、切页与历史、命令面板、主题/密度、移动导航、确认取消、编辑器预览与设置抽屉、减少动态与动画清理。业务写入使用隔离测试环境，真实内容不得作为测试夹具。
