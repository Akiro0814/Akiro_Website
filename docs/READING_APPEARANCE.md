# 阅读与默认外观

## Claude 配色参考

参考 [Claude 官方站点](https://claude.com/) 与 [Anthropic](https://www.anthropic.com/)，2026-10-20 核对官方页面 CSS：`--color-gray-050: #faf9f5`、`--color-gray-150: #f0eee6`、`--color-gray-200: #e8e6dc`、`--color-gray-950: #141413`、`--color-clay: #d97757`、`--color-clay-hover: #c6613f`。

默认 `life` 风格保留既有布局与得意黑，使用暖纸背景、象牙色辅助表面、炭黑正文与陶土装饰。小字强调色使用更深的 `#a94e32`，避免直接用浅陶土橙造成对比不足；深色风格采用暖炭灰与浅陶土。既有其他四种风格和用户手选偏好继续可用，不强制重置浏览器设置。

## 光标与章节定位

首次访问和「恢复光标默认」均关闭平滑跟随；自定义箭头仍精确跟手。已主动保存的 `smooth: true` 保留，访客可在设置中开启。此项与关闭整个自定义箭头的 `enabled` 开关独立。

目录点击直接按元素 ID 定位，统一计算导航下缘加 24px 的留白；阻止该次事件继续被原生锚点、Astro 或 Lenis 重复处理。存在 Lenis 时通过页面滚动事件同步其内部目标，使用 0.5s 定位；减少动态效果时立即定位。无 Lenis 时使用原生滚动。章节 hash 使用 replaceState 更新，重复点击同一章节仍会重新定位。

## 评论与渐进模糊

官方 Twikoo 标签和输入共用一块圆角表面，输入自身不再绘制第二重边框/圆角，聚焦反馈作用于外框；隐藏撰写区的重复匿名头像，保留已发表评论的头像与身份。官方提交、校验、草稿与后台管理流程保持可用。

`ProgressiveBlur.astro` 以 0.5/1/2/4/8/14px 六层模糊叠加渐变蒙版，在首页文章/项目横轨、关于拼贴及目录滚动边缘复用。仅在内容确实被裁切时启用对应一侧；卡片中央保持清晰，覆盖层不接收指针事件。指针滚动、窗口/字体/内容尺寸变化后更新可见边界；减少透明度时关闭背景滤镜。

裁切内容本身与模糊层一同渐隐，避免模糊到边缘后仍被矩形硬切。横向区域的过渡宽度为 28–80px，且覆盖层的上下交界额外羽化；纵向区域采用相同处理并对左右交界羽化。首尾内容完整显示时不启用对应一侧，避免无故遮挡文字。

壁纸上的次级按钮在正常、悬停和键盘焦点状态使用同一高对比浅色文字。导航品牌、链接和工具使用独立主题底色，整体玻璃保持统一透明材质，不恢复已移除的中间色带。

## 验证

`npm run test:reading-ui` 验证新访客默认开关、默认配色、真实文章目录反复跳转、减少动画、渐进模糊背景像素变化、按钮与品牌明暗对比、评论控件统一轮廓及 390px。对比度检查把实际计算颜色分别合成到纯黑与纯白背景上，要求默认风格浅/深模式下的品牌、品牌副标题和次级按钮达到 4.5:1。

测试截图 `reading-*` 位于本机忽略目录 `docs/assets/spring-ui/`。该脚本隔离动态 API，评论截图中的测试服务错误不代表实际后台故障；真实提交与管理闭环使用 `npm run test:twikoo-ui` 单独验证。
