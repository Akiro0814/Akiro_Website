# 首页随机壁纸

把自己的图片放进项目的 `public/wallpapers/` 顶层目录即可。在本机，完整路径为：

`E:\Project\L1angK1NG_Website\public\wallpapers\`

支持 JPG、JPEG、PNG、WebP、AVIF、GIF，扩展名不区分大小写。文件名可包含中文、空格、`#` 等字符，会自动编码 URL。不扫描子文件夹、隐藏文件、SVG、视频、符号链接或 Windows junction；目录本身为链接时也不扫描。建议使用清晰且文字较少的横向照片。

后台「页面内容 → 默认外观」可选择随机壁纸、固定背景或纯渐变，模式设置需要构建发布后生效。随机模式下，首页每次进入或刷新都会重新随机选择；有多张图片时尽量避免与本标签页上一次相同。只有一张图片时正常显示该图片。目录没有图片时，使用后台配置的 `hero.backgroundUrl` 作为旧背景回退；该字段也为空时显示渐变。图片加载失败时依次回退到旧背景、渐变。固定模式只使用配置的图片或视频，不从目录随机取图。

## 开发与生产

- 开发环境运行 `npm run dev` 和 `npm run admin`。新增或移除图片后重新进入首页即可，后台实时接口会更新列表。
- 后台提供 `GET /api/public/wallpapers` 实时目录清单，并通过 `GET /api/public/wallpapers/:filename` 安全读取图片。生产环境沿用现有 `/api/` 反向代理，因此放入服务器项目的 `public/wallpapers/` 后无需重新构建，图片内容也无需等待发布快照更新。
- 仅使用静态托管且没有后台服务时，首页使用构建清单随机显示。新增、移除图片后需要重新构建与上传静态产物；随机选择仍在浏览器每次进入首页执行。
- 每次 Astro 构建会扫描当前目录，并把普通图片按 `public/` 的原有规则复制到静态产物。

## 个人图片与备份

该目录下的图片已被 Git 忽略，仓库仅保留 `.gitkeep`，不会提交私人照片。它们仍会出现在你主动生成、部署的站点静态产物中。当前本机样例为 `public/wallpapers/akiro-landscape.jpg`，复制自本站原有上传照片，原件保留在 `public/uploads/`。

现有媒体备份主要覆盖 `public/uploads/`，请另行备份 `public/wallpapers/`。清空壁纸目录只需自行移走图片，保留 `.gitkeep` 即可。
