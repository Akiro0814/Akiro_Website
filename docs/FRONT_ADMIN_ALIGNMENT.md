# 前后台配置对齐

继续使用 Astro 静态前台与 Express 管理服务。后台「页面内容」使用与前台相同的配置契约，数据保存在 `data/profile.json`；缺失字段保留默认值，显式清空的社交链接、关于标签及页脚链接不会重新变回示例内容。

| 管理入口 | 实际控制内容 | 生效方式 |
| --- | --- | --- |
| 页面内容 → 站点品牌 | 站点名、作者、描述、头像与页标、导航副标题 | 保存后构建发布 |
| 页面内容 → 导航 | 顶部公开页面入口，可全部取消 | 保存后构建发布 |
| 页面内容 → 首页 | 轮换文字、区块文案、文章与项目数量、文章/状态/统计/项目/结语开关 | 保存后构建发布 |
| 页面内容 → 默认外观 | 五种风格、手动/时间/滚动模式、明暗主题、背景来源 | 保存后构建发布 |
| 页面内容 → 原有首页、关于、页脚设置 | 个人简介、社交链接、固定图片/视频背景、关于内容及页脚链接 | 保存后构建发布 |
| 项目管理 → 精选 | 首页项目横轨仅展示精选项目；项目列表仍展示公开项目 | 保存后构建发布 |
| 项目管理 + GitHub 仓库 | 关于页、项目页共用卡片与清单；按仓库地址合并，保留后台封面、介绍和详情入口，按星标排序 | 后台运行时自动同步，无需为星标重新构建；项目详情正文仍按原流程构建发布 |
| 本地 `public/wallpapers/` | 随机模式的图片池，后台可刷新预览 | 有后台服务时，增删图片后重新进入首页；纯静态托管需重新构建 |
| 音乐管理 | 本地歌曲与受管理的公开歌单 | 前台重新加载歌单后生效，无需额外配置网易云歌单 ID |
| 评论 → Twikoo 完整管理 | 官方评论、审核、博主回复、配置、导入导出 | 与前台同一数据库，操作即时生效，无需构建 |

已有访客自行选择的外观仍优先；外观面板的「恢复站点默认」会清除本机风格和明暗偏好，应用后台发布的默认值。时间、滚动模式会继续按各自规则切换。

关于页和项目页均展示 `src/data/site.config.json` 中 `githubUser` 的全部公开非 fork 仓库、后台管理项目及手动项目组，统一去重和排序。GitHub 仓库按每页 100 条完整分页，显示包括 0 在内的实际 Star 数；本地独立项目不显示虚构星标。两页进入时读取同一公开接口，停留期间每五分钟检查一次，返回浏览器标签页时也会检查。后台缓存 GitHub 响应五分钟，并将公开元数据保存到 `data/github-projects.json`，限流、断网和重启后优先保留完整快照；构建时只读 GitHub，不改写源码，不会因悬停预取触发整页刷新。纯静态托管或后台不可用时保留构建快照，星标随下次构建更新。

后台保存会提示未保存、保存中及保存结果；离开有改动的页面时提供确认。表单内的文字预览帮助核对文案，并非完整前台渲染。构建发布仍使用原有流程，不把保存成功当作已上线。

后台新增分区错峰进场、列表新增行显现、详情展开、按钮按压、悬停光影和保存状态反馈。切页会清理监听器与动画；系统设置减少动态效果时直接呈现最终状态。

音乐方面，后台返回空歌单表示已撤下全部歌曲，前台会隐藏播放器，不再回退到旧的远程歌单。验证使用浏览器隔离响应和本地生成 WAV，证明无网易云 ID 时能实际播放；不据此承诺第三方音乐源、线上代理或跨域服务可用。

前台左下角「外观设置 → 光标设置」属于访客的本机偏好，不写入后台。新访客默认关闭平滑跟随，保留精确跟手的自定义箭头；用户主动保存的开启/关闭选择继续优先。可独立开关自定义光标和平滑跟随，并调节跟随柔和度、跟随幅度、大小、悬停放大、按下缩放、过渡时长；即时生效并保存在当前浏览器，刷新或跨页后保留。「恢复光标默认」恢复平滑跟随关闭，并只清除光标偏好，不影响页面主题与视觉风格。开启跟随后，初始柔和度为 70ms、跟随幅度为 24px，使用距离自适应连续缓动；幅度参数不代表硬截断距离。旧版未调节的 95ms/48px 参数组合自动迁移，自定义组合保留。光标宽度仍为 24px；点击/拖动精确定位，触屏不启用自定义指针，减少动态效果时保留参数但暂停跟随和缩放。

Twikoo 接入与备份说明见 [TWIKOO.md](TWIKOO.md)。默认自托管使用官方 Loki 数据库；完整管理面板复用博客登录，核心 SDK 在本站加载。评论操作与普通页面内容配置的构建发布流程不同。
