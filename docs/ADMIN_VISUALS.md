# 后台视觉与交互

后台在现有 Express 模板上使用暖色珍珠玻璃视觉，参考 scaffold-master `577079e`。
主色、暖白背景和霞鹜文楷继续沿用博客，玻璃浮层、高光与图表采用淡红和低饱和暖色。

## 入口

```powershell
npm ci
npm run admin
```

登录既有后台 `/admin`。主题和密度在顶栏「外观设置」中调整，`Ctrl/Cmd + K`
打开页面搜索与快捷操作，输入 `?` 显示基于现有博客规则的帮助。
偏好只在当前浏览器保存；主题可选浅色、深色或跟随系统。

文章与随笔提供表格、看板、状态矩阵、按内容日期排列的时间轴泳道和分类关系图，选择分类可展开内容；画布支持
平移、缩放、暂停和重播。列表筛选与分页作用于当前已加载内容。
文章设置位于右侧抽屉，原来的保存、草稿、预览、插图、未保存保护保持有效。

导航管理提供分类星图；页面文案提供可折叠样本卡及未保存字段浮条；发布页提供
构建流程与版本阶梯；站点数据增加每日访问热力。原系统的组织、角色授权和代码生成
业务未引入：矩阵、画布、样本册与流水线视觉分别映射到博客已有内容及发布流程。
没有小时级统计时不显示虚构的 7×24 热力，没有独立步骤事件时不展示虚构发布进度。

## 实现位置

- `admin/public/pearl.css`：主题、材质、控件、布局、图表与响应式；在既有业务 CSS 后加载。
- `admin/public/motion.js`：GSAP 统一动效、Flip 布局重排、数字滚动、图表、共享元素和帧循环。
- `admin/public/interface.js`：浮层焦点、异步确认、Toast、外观、菜单、命令、下拉、列表增强与设置抽屉。
- `admin/public/visualizations.js`：真实数据驱动的看板、状态矩阵、关系图、导航图、热力与发布版式。
- `admin/public/login-scene.js`：登录画布、时钟、轻倾和成功反馈。
- `admin/public/ui-model.js`：可独立测试的外观、命令、关系数据与热力模型。

GSAP 与 Flip 从安装的 npm 依赖通过两个限定的同源资源路径提供，无 CDN 请求，
不公开整个 node_modules。来源与许可见根目录 `THIRD_PARTY_NOTICES.md`。

## 隔离预览与验收

```powershell
npm run admin:preview
```

独立预览运行在 `http://localhost:4413/admin`，账号 `preview`，密码
`visual-preview-only`。只使用系统临时目录中的生成内容，关闭远端备份；退出时清理。
该账号仅供这个临时服务，不是正式后台账号。正式后台的源内容、配置与发布链接不被改写。

```powershell
npx playwright install chromium
npm run test:admin-ui
npm run verify
```

浏览器回归自动创建 4414 端口的独立服务，验证登录、各模块导航、主题密度、
筛选分页、各视图、图谱控制、确认取消、编辑器预览与未保存保护、设置保存、
热力、减少动态和手机布局。截图为生成的测试数据，保存至 `docs/assets/admin-pearl/`。
真实线上发布、远程备份和外部音乐服务不由 UI 测试触发。

持续画布在隐藏/离屏时暂停，组件换页时清理；系统开启减少动态时直接显示静态终态。
弹窗使用焦点约束，Escape 关闭顶层浮层，关闭后返回触发控件。
